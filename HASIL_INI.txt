PROBLEM:
  Terminal Anda buka di folder yang salah!
  D:\laragon\www (SALAH) 
  Seharusnya: C:\...\E-Kost Manager\Back End

═══════════════════════════════════════════════════════════════
  SOLUSI TERBAIK:
═══════════════════════════════════════════════════════════════

PILIHAN 1: Double-click File (.bat)
   Navigate ke: Back End\RUN_SERVER.bat
   Double-click file tersebut
   Server akan jalan otomatis

PILIHAN 2: Buka Terminal di Folder yang Benar
   
   Di Command Prompt, ketik:
   
   cd "C:\Users\USER\OneDrive\Desktop\E-Kost Manager\Back End"
   php artisan serve --port=8080

PILIHAN 3: Pakai Laragon (Recommended)
   
   1. Buka Laragon
   2. Di sisi kiri, cari folder: E-Kost Manager
   3. Klik kanan → "Open in Terminal"
   4. Ketik: 
      cd "Back End"
      php artisan serve --port=8080

═══════════════════════════════════════════════════════════════
  KONFIGURASI FRONTEND:
═══════════════════════════════════════════════════════════════

Setelah backend jalan di port 8080:

1. Buka folder: Front End
2. Edit file .env
3. Pastikan ada ini:
   VITE_API_URL=http://localhost:8080/api

4. Jalankan:
   npm run dev
