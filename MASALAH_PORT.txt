═══════════════════════════════════════════════════════════════
                ERROR: Port 8000 Already Used
═══════════════════════════════════════════════════════════════

PESAN ERROR:
   "Failed to listen on 127.0.0.1:8000"

ARTINYA:
   Port 8000 sudah dipakai aplikasi lain
   (mungkin Laragon, IIS, atau aplikasi lain)

═══════════════════════════════════════════════════════════════
   SOLUSI (PILIH SALAH SATU):
═══════════════════════════════════════════════════════════════

CARA 1 - Double-click File (.bat):
   
   Double-click: Back End\FIX_PORT.bat
   
   Server akan jalan di port 8080 atau 8081

CARA 2 - Manual (Copy-paste di CMD):
   
   cd "C:\Users\USER\OneDrive\Desktop\E-Kost Manager\Back End"
   php artisan serve --port=8080

CARA 3 - Cari Port yang Available:
   
   cd "C:\Users\USER\OneDrive\Desktop\E-Kost Manager\Back End"
   php artisan serve --port=3000

═══════════════════════════════════════════════════════════════
   PENTING - UPDATE FRONTEND .env:
═══════════════════════════════════════════════════════════════

Setelah backend jalan, SUPAYA PORT BISA DIPAKAI:

   Jika backend jalan di port 8080:
      VITE_API_URL=http://localhost:8080/api

   Jika backend jalan di port 8081:
      VITE_API_URL=http://localhost:8081/api

   Jika backend jalan di port 3000:
      VITE_API_URL=http://localhost:3000/api

═══════════════════════════════════════════════════════════════
   CARA CEK PORT BERAPA YANG DIGUNAKAN:
═══════════════════════════════════════════════════════════════

   Nanti ada pesan seperti ini di terminal:
   
   "Laravel development server started:
    http://127.0.0.1:8080"
   
   Nah, itu berarti port yang dipakai: 8080

   QUICK FIX:
═══════════════════════════════════════════════════════════════

   Double-click: Back End\FIX_PORT.bat

      VITE_API_URL=<URL_YANG_DICOPY>/api
